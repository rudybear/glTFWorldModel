# Outreach assets manifest

All images are real renders/plots produced from this repo's actual data and run outputs (no mockups). Generated on branch `ext-state-series-proposal`. GPU/EGL was available (NVIDIA RTX PRO 6000 Blackwell, driver 580.178.04) and used for every render below.

- `pipeline_frame_rgb_seg_depth.png` — 3-panel strip (RGB | segmentation, one flat color per object id | depth, viridis colormap) for one stored frame from `data/perception-v1/episodes/ep_000055/{rgb,seg,depth}.npy`, frame index 50 (5 objects visible: ground + 4 falling primitives).
- `closed_loop_strip.png` — 4 timesteps (t=0, 33, 66, 99 of 100; 30 fps) extracted from `runs/closed-loop-v1/video/ep_000060_3panel.mp4` and tiled vertically; each row's 3 panels are GT | Arm A (oracle dynamics rollout) | Arm C (real visual closed loop), per `gltfworld.eval.closed_loop`'s `three_panel = [gt, armA, armC]` video layout.
- `attribution.png` — unmodified copy of `runs/closed-loop-v1/attribution.png`.
- `divergence_curve.png` — unmodified copy of `runs/dynamics-v1/eval/divergence_curve.png`.
- `crosscheck_side_by_side.png` — output of `uv run gltfworld crosscheck data/dynamics-v1/episodes/ep_000700.glb`, frame 0, 256px renders; panels are gltfworld/pyrender | MuJoCo (independent oracle) | diff mask (white=both render this pixel as an object, red=gltfworld-only, blue=MuJoCo-only). Reported binary silhouette IoU = 0.9922 (5/5 objects each at per-object IoU 1.0000).
- `door_opening_strip.png` — 4 frames (t=0, 4, 7, 9 of 100, dt=0.034s) from `data/articulated-v1/episodes/ep_000076.glb` (a cabinet with a `revolute` door joint, `part_labels=('door',)`), rendered with `EpisodeRenderer` at 512x512 and cropped to the same object-region rectangle in every frame (the dataset's camera places this small cabinet in the lower-left of an otherwise-empty frame; crop removes only the empty black margin, applied identically across all 4 frames). Joint angle goes 14 deg -> 29 deg -> 77 deg -> 112 deg (opening past perpendicular before the scripted push's later frames let it settle back).
- `physion_converted_render.png` — frame 0 of the converted Physion/Collide trial `pilot_it2_collision_yeet_box_1_dis_1_occ_0008.glb` (`data/external/physion/glb/Collide/`), rendered at 800x800 with `EpisodeRenderer`. Note: every sampled converted-Physion GLB carries zero light nodes (confirmed on 30+ trials), so an as-converted render is literally all-black under pyrender's PBR shading (no light source at all, not a bad camera angle); a simple 6-directional light rig was added in-memory (render-time only, never written back to any file) purely so the real converted geometry/camera/poses become visible. Object geometry, sizes, colors, poses, and camera are the unmodified converted data.
- `gt_vs_pred_perception.png` — 2-panel strip for `data/perception-v1` episode `ep_000060`, frame 46: left is the stored GT render (`data/perception-v1/episodes/ep_000060/rgb.npy[46]`); right is `EpisodeRenderer`'s render of the corresponding predicted-scene GLB `runs/perception-v4-cnn-40k/eval/pred_frames/ep_000060_f0046.glb` (PerceptionDETR's thresholded detections at that frame, built by `gltfworld.eval.perception_eval.render_check`; object colors/material are GT-assist-copied from the Hungarian-matched real object per that eval's documented convention, since the detector itself never predicts color).
